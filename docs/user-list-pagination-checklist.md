# 사용자 목록 페이지네이션·퀴즈 아이콘 확인 목록

대상: 2026-09-09 승인 변경. 아래 체크박스는 **실제 화면 수동 확인용**이며 자동 테스트 통과와 구분한다.

## 공통 목록

- [ ] 시험목록·내/공개 개념노트·복습표시는 기본 5개씩 보인다.
- [ ] FAQ는 10개씩, 응시 이력은 기존 10개씩 보인다.
- [ ] 전체 건수와 현재 표시 범위가 결과에 맞고 이전·번호·다음으로 이동한다.
- [ ] 페이지가 많아도 모든 번호가 길게 나열되지 않고 생략 표시된다.
- [ ] 한 페이지 이하일 때 불필요한 이동 버튼이 없고 빈 결과도 정상 안내된다.
- [ ] 페이지 크기·검색·필터를 바꾸면 첫 페이지로 돌아간다.
- [ ] 페이지 이동 시 목록 상단으로 이동하며 모바일 고정 헤더에 가리지 않는다.
- [ ] 빠르게 검색/페이지를 바꿔도 이전 응답이 최신 결과를 덮어쓰지 않는다.
- [ ] 요청 실패가 빈 결과 또는 오래된 결과로 오인되지 않는다.
- [ ] 다크모드에서 현재 페이지·버튼·건수가 구분된다.

## 시험목록

- [ ] 전체 데이터 기준으로 제목·관심시험·유형·연도·회차·AI 필터가 함께 적용된다.
- [ ] 500건 이후에 위치한 시험도 검색·페이지 이동으로 접근할 수 있다.
- [ ] 페이지를 이동해도 연도·회차 선택지가 사라지지 않는다.
- [ ] 시험 시작 모달과 실제 시험 진입은 기존대로 동작한다.

## 개념노트

- [ ] 다른 페이지에 있던 노트도 제목 검색으로 찾을 수 있다.
- [ ] 검색 결과가 여러 페이지이면 페이지 이동이 유지된다.
- [ ] 내 노트 목록/검색에는 다른 사용자의 노트가 섞이지 않는다.
- [ ] 마지막 페이지의 마지막 노트를 삭제하면 이전 페이지로 복구된다.
- [ ] 공개 개념노트의 검색·상세 진입은 유지된다.
- [ ] 기존 Notion 내보내기 동작은 유지된다.

## 복습 표시·FAQ·응시 이력

- [ ] 마지막 페이지에서 복습 표시를 해제하면 빈 페이지에 머무르지 않는다.
- [ ] 목록의 현재 페이지와 관계없이 전체 복습 시작 대상은 기존과 같다.
- [ ] FAQ 답변 아코디언은 페이지 안에서 정상적으로 열리고 닫힌다.
- [ ] 응시 이력 페이지 번호 이동 후 해당 이력 상세로 진입한다.

## 퀴즈

- [ ] 코드·SQL/데이터베이스·스케줄링·문제유형·시험분야의 아이콘이 주제와 맞는다.
- [ ] 등록 순서를 바꾸어도 같은 카테고리의 아이콘이 바뀌지 않는다.
- [ ] 알 수 없는 새 카테고리도 기본 아이콘과 이름을 정상 표시한다.
- [ ] 관심시험 필터, 언어/출처 선택 모달, AI 전체 퀴즈 진입은 그대로 동작한다.

## 자동 검증 결과

- 프론트: 관련 Jest 9 suites / 34 tests 통과, 타입 검사 통과, 격리 프로덕션 빌드 성공(기존 viewport metadata 경고).
- 백엔드: 전체 458 tests 통과. 이후 실제 PostgreSQL에서 발견한 nullable 검색 파라미터 타입 오류를 수정하고, 영향 범위 13 tests를 추가 재검증해 통과.
- 독립 정적 검증: 검색/페이지 경계/조회 경합/소유권/퀴즈 아이콘 및 후속 CAST 수정 승인.
- 실제 브라우저: 퀴즈의 카테고리 아이콘(소프트웨어공학·관계형 DB 이론·웹 기술 포함), 개념노트의 기본5개 선택·전체건수·다크모드 화면 확인. 최종 PostgreSQL 시험목록 기본조회 1–5/전체14건 및 다음페이지 6–10/14건, 내노트 기본조회 1–1/1건 성공. 실제 사용자 데이터를 생성·삭제하는 수동 테스트는 수행하지 않음.
- 위 자동 검증 결과는 수동 체크박스를 대신하지 않는다. 최신 서버 상태는 `docs/agent-handoff/CURRENT.md` 참고.
